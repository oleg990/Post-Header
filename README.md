# Post Header — прототип рендера

Текст поста (с эмодзи) → JPG в фирменном стиле «Адреса»: шапка с логотипом и адресом, золотые иконки, несколько вариантов оформления.

## Запуск (консольный прототип)

```
go run ./cmd/postheader-cli -in examples/post1.txt -logo examples/logo-adresa.jpg -phone 89205952888 -n 4 -format story
```

Флаги: `-n` сколько вариантов, `-format story|portrait|square|all`, `-bg black|white|graphite|photo -photo файл.jpg`, `-font arial.ttf -font-bold arialbd.ttf` (свой шрифт, недостающие символы берутся из Inter), `-icons 2=gift,5=house` (иконки вручную),
`-slides` (делить длинный текст на слайды вместо уменьшения шрифта), `-phone`, `-phone-at header|footer`, `-address`.

## Разметка текста
- пустая строка или строка «.» — новый блок (у каждого блока своя иконка);
- «– пункт» — список с висячим отступом, строка «(…)» после пункта — его продолжение;
- строка ЗАГЛАВНЫМИ или короткая «…!» в начале блока — золотой заголовок;
- `**текст**` и суммы «10%», «3000р», «₽» — золотой акцент;
- эмодзи в начале блока выбирает иконку (✅ галочка, ❗ восклицание, 🎁 подарок, 🏠 дом, 📍 метка, 💰 процент).

## Структура
- `internal/render` — движок рендера без GUI (его же вызывает десктоп-приложение)
- `assets` — встроенные шрифты Inter (OFL) и Twemoji SVG (CC-BY 4.0, нужна атрибуция в «О программе»)
- `cmd/postheader-cli` — консольная обёртка

Совместимость: код держим в рамках Go 1.20 (последний с официальной поддержкой Windows 7).
