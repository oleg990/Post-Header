# Post Header — прототип рендера

Текст поста (с эмодзи) → JPG в фирменном стиле «Адреса»: шапка с логотипом и адресом, золотые иконки, несколько вариантов оформления.

## Запуск (консольный прототип)

```
go run ./cmd/postheader-cli -in examples/post1.txt -logo examples/logo-adresa.jpg -phone 89205952888 -n 4 -format story
```

Флаги: `-n` сколько вариантов, `-format story|portrait|square|all`, `-bg black|white|graphite|photo -photo файл.jpg`, `-font arial.ttf -font-bold arialbd.ttf` (свой шрифт, недостающие символы берутся из Inter), `-icons 2=gift,5=house` (иконки вручную),
`-slides` (делить длинный текст на слайды вместо уменьшения шрифта), `-phone`, `-phone-at header|footer`, `-address`.

## Разметка текста
- пустая строка или строка «.» — новый блок (у каждого блока своя иконка);
- «– пункт» — список с висячим отступом, «1. пункт» или «1) пункт» — нумерованный список с золотыми номерами, строка «(…)» после пункта — его продолжение;
- строка ЗАГЛАВНЫМИ или короткая «…!» в начале блока — золотой заголовок;
- `**текст**` и суммы «10%», «3000р», «₽» — золотой акцент;
- эмодзи в начале блока выбирает иконку (✅ галочка, ❗ восклицание, 🎁 подарок, 🏠 дом, 📍 метка, 💰 процент).

В окне под полем текста есть кнопки «– Пункт», «1. Список», «Заголовок», «Золотом», «+ Блок», «Эмодзи» и «Причесать» (убирает лишние пробелы и пустые строки). Кнопки работают как переключатели, Ctrl+Z отменяет.

## Структура
- `internal/render` — движок рендера без GUI (его же вызывает десктоп-приложение)
- `assets` — встроенные шрифты Inter (OFL) и Twemoji SVG (CC-BY 4.0, нужна атрибуция в «О программе»)
- `cmd/postheader-cli` — консольная обёртка

Совместимость: код держим в рамках Go 1.20 (последний с официальной поддержкой Windows 7).

## Окно программы

`cmd/postheader` — десктоп-приложение на Gio (`internal/ui`): заставка, редактор с цветными эмодзи, живое превью вариантов, сохранение и копирование в буфер, настройки (логотип, адрес, шрифт). Настройки и черновик хранятся в `%APPDATA%\PostHeader\config.json`, готовые посты — в `Изображения\PostHeader`.

Сборка для Windows (без консольного окна):

```
GOOS=windows go build -ldflags "-H windowsgui" -o PostHeader.exe ./cmd/postheader
```

Готовые .exe (64 и 32 бита) собирает GitHub Actions на Go 1.20.14 — артефакт `postheader-windows`, а по тегу `v*` — релиз.

Для разработки на Linux окно собирается с Go ≤ 1.23 (cgo-ограничение Go 1.24 в Gio 0.6) и пакетами `libwayland-dev libxkbcommon-x11-dev libgles2-mesa-dev libegl1-mesa-dev libx11-xcb-dev libxcursor-dev libxfixes-dev libvulkan-dev`.

## Установка и обновления

Коллегам достаточно скачать `PostHeader-Setup-vX.Y.Z.exe` со страницы
[Releases](https://github.com/oleg990/Post-Header/releases/latest) и запустить:
права администратора не нужны, программа ставится в профиль пользователя,
появляются ярлыки в «Пуске» и на рабочем столе. 64-битная сборка ставится
автоматически там, где это возможно.

Новая версия выпускается так: поменять число в файле `VERSION` (например, `0.2.0`)
и отправить в main. CI соберёт exe и установщик (`installer/PostHeader.iss`, Inno Setup 6.2.2)
и опубликует релиз `v0.2.0` (тег `v*` тоже работает). Установленная программа при запуске проверяет последний
релиз и показывает кнопку «Обновить до vX»: установщик скачивается, ставится
тихо и снова открывает программу. Тестовые сборки (`dev-…`) не обновляются.
